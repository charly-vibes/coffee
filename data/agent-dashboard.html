Definición de tarea

una tarea = un prompt de usuario y los turnos que dispara hasta el prompt siguiente; el tiempo del agente es la suma de los turnos (durationMs reportado, o gap desde el evento previo con tope gap_cap).

Límites declarados

  • abort_signal: solo pi registra stopReason aborted/error; claude-cli no escribe esa señal
  • fork_dedupe: sesiones pi con el mismo id = fork: se toma el archivo más largo
  • Volumen del reporte: “interacciones” son llamadas de API (incluye tool calls); no se comparan 1:1 con los prompts del talk.
