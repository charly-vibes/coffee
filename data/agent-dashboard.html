Definición de tarea

una tarea = un prompt de usuario y los turnos que dispara hasta el prompt siguiente; el tiempo del agente es la suma de los turnos (durationMs reportado, o gap desde el evento previo con tope gap_cap). coffe-dnx.3: una tarea no cruza sesiones — si el prompt siguiente abre otra sesión, es otra tarea; sid indexa sessions[] = {source, project, session_id}, y cost/tokens suman los turnos assistant de la tarea.

Límites declarados

  • abort_signal: solo pi registra stopReason aborted/error; claude-cli no escribe esa señal
  • fork_dedupe: sesiones pi con el mismo id = fork: se toma el archivo más largo
  • Turnos sin prompt previo: 543116 (sesiones retomadas: no abren tarea, no se cuentan como prompt).
  • Prompts inyectados excluidos (claude-cli): 61 preámbulos de reanudación.
  • Raíces de repos ausentes: ninguna.
  • Volumen del reporte: “interacciones” son llamadas de API (incluye tool calls); no se comparan 1:1 con los prompts del talk.
